This is an archived snapshot of requirements from v1.0. For current requirements, see the active .planning/REQUIREMENTS.md file.

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Core Infrastructure

- [x] **CORE-01**: Accept file input (single file, path to binary/archive/image)
- [x] **CORE-02**: Accept directory input (path containing multiple challenge files)
- [x] **CORE-03**: Accept URL input (web service URL, nc/tcp endpoint)
- [x] **CORE-04**: Detect flag format pattern `flag{...}`, `FLAG{...}`, `CTF{...}`
- [x] **CORE-05**: Extract and output flag to stdout
- [x] **CORE-06**: Basic encoding/decoding (base64, hex, URL, ROT13)
- [x] **CORE-07**: Tool availability checking (verify required tools installed)
- [x] **CORE-08**: Command timeout handling (prevent infinite loops)
- [x] **CORE-09**: Verbose mode (`-v` flag) for detailed output

### Challenge Detection

- [x] **DET-01**: Automatic category detection via file type/magic bytes
- [x] **DET-02**: Automatic category detection via network response analysis
- [x] **DET-03**: Automatic category detection via content heuristics
- [x] **DET-04**: `--force` flag to override auto-detection with specified category

### Web Solver

- [x] **WEB-01**: HTTP GET request with custom headers
- [x] **WEB-02**: HTTP POST request with body data
- [x] **WEB-03**: Follow redirects automatically
- [x] **WEB-04**: Parse JSON responses (jq or text parsing)
- [x] **WEB-05**: Basic SQL injection detection and exploitation
- [x] **WEB-06**: Basic command injection detection and exploitation
- [x] **WEB-07**: Session handling and cookie management

### OSINT Solver

- [x] **OSINT-01**: DNS lookup (dig, nslookup)
- [x] **OSINT-02**: WHOIS lookup
- [x] **OSINT-03**: HTTP header inspection
- [x] **OSINT-04**: Source code scraping from web pages
- [x] **OSINT-05**: Git repository analysis (git log, diff, secrets)

### Crypto Solver

- [x] **CRYPTO-01**: Identify common encodings (base64, hex, rot13, Caesar)
- [x] **CRYPTO-02**: OpenSSL-based decryption for known ciphers (AES, DES, RSA)
- [x] **CRYPTO-03**: XOR brute-force for short keys
- [x] **CRYPTO-04**: Hash identification and cracking (md5, sha1, sha256)
- [x] **CRYPTO-05**: Custom cipher implementation (Vigenere, substitution)

### Forensics Solver

- [x] **FOREN-01**: File type identification (magic bytes)
- [x] **FOREN-02**: String extraction (strings, grep)
- [x] **FOREN-03**: Hexdump analysis (xxd, hexdump)
- [x] **FOREN-04**: Archive extraction (tar, unzip, gzip, 7z)
- [x] **FOREN-05**: Steganography detection (file anomalies, hidden data)
- [x] **FOREN-06**: PNG metadata extraction (exif, binwalk)

### Reverse Engineer Solver

- [x] **REV-01**: Binary file type identification
- [x] **REV-02**: String extraction from binaries
- [x] **REV-03**: Symbol analysis (nm, readelf)
- [x] **REV-04**: Disassembly output (objdump)
- [x] **REV-05**: Shared library dependency analysis (ldd)
- [x] **REV-06**: Function signature identification

### PWN Solver

- [x] **PWN-01**: Binary format identification (ELF, PE)
- [x] **PWN-02**: Binary execution and I/O interaction (netcat pipe)
- [x] **PWN-03**: Basic buffer overflow detection via fuzzing
- [x] **PWN-04**: GDB integration for simple exploitation (scripted)
- [x] **PWN-05**: Return-to-libc / ROP chain construction for simple cases

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| AI/LLM integration | Pure bash constraint — no external API calls |
| Docker sandbox | No containerization per requirements |
| Required Python dependencies | Optional pwntools allowed but not required |
| GUI | Dark mode CLI only per requirements |
| Mobile/web frontend | CLI tool only |
